# Anti-Version Test Projects

Google Antigravity로 제작된 프로젝트 모음입니다.

## 📁 프로젝트 구성

### 1. `antigravity/` — Google Antigravity Next.js 랜딩페이지
Google DeepMind의 AI-First 자율 에이전트 개발 플랫폼 **Antigravity**를 소개하는 프리미엄 원페이지 랜딩페이지입니다.
- **Tech Stack**: Next.js 16 (App Router), TypeScript, Zero-Gravity Custom CSS
- **실행 방법**:
  ```bash
  cd antigravity
  npm install
  npm run dev
  ```

### 2. `apple-car/` — Apple Car "혁명의 시작" 랜딩페이지
Apple의 차세대 모빌리티 론칭 콘셉트를 담은 원페이지 사이트입니다.
- **Tech Stack**: HTML5, Vanilla CSS, JavaScript
- **포함 리소스**: Apple Car 스튜디오 뷰 및 공식 스토어 론칭 비주얼
